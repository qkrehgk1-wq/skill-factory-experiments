# SEO 롱테일 키워드 전략 v2

## 적용 범위

이 스킬은 **키워드 선택·콘텐츠 전략**만 다룬다. 색인 여부·robots·
sitemap·내부링크·title/meta 태그·이미지 alt·모바일 최적화·Core Web
Vitals·구조화 데이터 같은 **기술 SEO는 범위 밖**이다. "왜 노출이
전혀 안 되지?"가 콘텐츠 문제가 아니라 크롤링·색인 문제일 수도 있다는
점은 인지하되, 진단은 별도로 해야 한다.

## Why

신생 사이트가 대형 매체·기업 블로그와 같은 자리를 두고 경쟁하면, 검색
결과가 어떤 신호를 보고 순위를 매기든 실전에서는 대형 사이트가 이길
확률이 높다. "좋은 글을 쓰면 언젠가 뜬다"는 감이 아니라, **키워드를
쓰기 전에 승산을 판단**해야 발행 자체가 낭비되지 않는다.

## 핵심 개념 (정확성 유의)

- **"도메인 권위(Domain Authority)"는 Google이 공식 발표한 순위 지표가
  아니다** — 제3자 SEO 툴이 만든 참고 지표다. Google은 페이지 단위로
  다양한 신호와 여러 시스템을 함께 사용한다고 설명한다. 이 스킬에서는
  "도메인 권위 점수"라는 단일 수치 대신 **SERP 경쟁력 · 사이트 신뢰·
  평판 · 관련 주제 축적도 · 링크/브랜드 강도**라는 복합적 감각으로
  다룬다.
- **헤드 vs 롱테일은 단어 수만으로 가르지 않는다** — 단어 수는 거친
  참고치일 뿐이다. 두 단어짜리도 매우 구체적일 수 있고, 긴 문장도
  경쟁이 세고 의도가 애매할 수 있다. 실제로 볼 것은: 검색 의도의
  구체성, 주제 범위가 좁은지, SERP 경쟁이 약한지, 실제 수요가 있는지,
  사용자 문제가 명확한지 — 이 다섯을 종합해 롱테일 여부를 판단한다.
- **검색 의도(search intent)**: 정보성·거래성·탐색성·탐방성 중 어디에
  해당하는지 먼저 정의한다. 의도와 안 맞는 글은 사용자 목적을 충분히
  해결하지 못할 가능성이 높고, 그러면 검색 성과가 떨어질 수 있다.
  ("체류시간이 짧아지면 순위가 밀린다"처럼 단정적 인과관계로 말하지
  않는다 — Google이 공개적으로 확인한 단일 공식이 아니다.)
- **직접 경험(first-hand experience)은 품질을 높이는 요소이지, 그
  자체로 점수를 더 주는 별도 지표가 아니다** — E-E-A-T(경험·전문성·
  권위성·신뢰성)는 Google이 콘텐츠 품질을 설명하는 개념이지, 하나의
  직접적인 순위 산정 요소로 공식화된 게 아니다. "경험을 넣으면 점수가
  오른다"가 아니라 **"직접 경험·전문성·출처·작성자 정보 등은 신뢰성과
  유용성을 높이는 품질 요소"**라고 이해한다.
- **경쟁 강도는 추정하지 말고 실제로 확인한다** — 이게 이 스킬에서
  가장 중요한 원칙 변경이다. "대형 매체가 다룰 것 같다"는 감이 아니라,
  검색 도구를 쓸 수 있으면 실제 상위 결과를 확인한다(아래 절차 3 참고).
  도구가 없으면 추측하지 말고 "검색 결과 직접 확인 필요"라고 명시한다
  — 이 원칙은 그대로 유지한다.
- **차별화 가능 여부가 핵심 철학이다** — 이 사이트만 가진 것(직접
  만든 도구, 직접 겪은 경험, 실측 데이터, 직접 비교표)이 없으면
  보류를 권한다. 인터넷에 있는 글 10개를 요약해서 만드는 콘텐츠는
  대체 가능하다 — 원본 정보·원본 조사·직접 겪은 관점처럼 대체 불가능한
  것이 있어야 승산이 있다.

## 판정 절차

1. **의도 분류** — 이 검색을 한 사람이 진짜 원하는 게 뭔지(정보/거래/
   탐색/탐방) 한 문장으로 정의한다.
2. **구체성·수요 판단** — 단어 수가 아니라 검색 의도의 구체성과 주제
   범위로 헤드/롱테일 성격을 판단한다. 검색량 정보가 있으면 참고하되,
   검색량만으로 결정하지 않는다(수요가 아예 없는 키워드는 걸러내는
   용도로만 쓴다).
3. **실제 SERP 확인** — 검색 도구를 쓸 수 있으면 그 키워드로 실제
   검색해 상위 결과를 확인한다. 확인할 것: 대형 사이트/개인 블로그
   비율, 콘텐츠 최신성, 검색의도와 일치하는지, **빈틈이 있는지**(오래된
   정보, 얕은 답변, 직접 경험 부재, 이미지·가격정보 부족, FAQ 누락 등
   — 빈틈이 있으면 대형 사이트라도 이길 여지가 생긴다). 도구가 없으면
   "검색 결과 직접 확인 필요"라고 명시하고 다음 단계로 넘어가지 않는다.
4. **차별화 가능 여부** — 이 사이트만 가진 것(직접 만든 도구, 직접
   겪은 경험, 실측 데이터)으로 이 주제를 쓸 수 있는지, 그리고 이
   사이트가 애초에 이 주제를 다뤄야 할 이유가 있는지(주제 적합성)를
   함께 확인한다. 둘 다 없으면 보류를 권한다.
5. **글 구조 매칭** — 검색 의도에 맞는 구조(소제목·FAQ·실전 팁·데이터
   인용)를 제안한다.
6. **(있으면) 실측 데이터 반영** — 이미 운영 중인 사이트이고 검색
   성과 데이터(노출·클릭·평균순위 등)를 알고 있다면 판단에 반영한다.
   예: 노출은 많은데 클릭이 적으면 제목·설명 문제일 가능성, 평균순위가
   11~20위대면 보완만으로 진입권 후보. 이런 데이터가 없다면 이 단계는
   생략하고 추측하지 않는다.

## 체크리스트 (놓치기 쉬운 것)

- [ ] "도메인 권위 점수"를 Google 공식 지표처럼 단정 — 참고 개념일 뿐
- [ ] 단어 수만 세고 롱테일이라 판정 — 의도 구체성·경쟁 강도를 봐야 함
- [ ] "체류시간이 짧아 순위가 밀린다"처럼 확정된 공식으로 말함 —
      검색 성과가 떨어질 "가능성"으로 표현해야 함
- [ ] 경쟁자를 실제로 안 보고 추정만으로 판정 — 도구가 있으면 반드시
      실제 검색 결과를 확인
- [ ] 이 사이트만 가진 것(도구·경험·데이터) 없이 쓰는 글은 대체 가능한
      콘텐츠라 우선순위가 낮다
- [ ] 상위 결과의 "빈틈"을 안 보고 그냥 "대형 사이트라 못 이긴다"고
      포기 — 빈틈이 있으면 승산이 생긴다

## 출력 형식

키워드 후보가 주어지면 다음 순서로 답한다:
1. 검색 의도 한 문장 정의
2. 헤드/롱테일 성격 판단과 근거(단어 수가 아니라 구체성·경쟁 기준)
3. 실제 SERP 확인 결과(도구로 확인했다면 상위 결과 요약과 빈틈, 못
   했다면 "검색 결과 직접 확인 필요"라고 명시)
4. 이 키워드에서 이길 수 있는지 없는지 판정(승산 있음/불확실/승산 없음)
5. 승산이 있다면 추천 글 구조, 없다면 대체 키워드 방향 제안
6. 이 사이트만 가진 차별화 요소를 살릴 수 있는 각도

실제 검색 결과를 확인할 수 없는 상태에서는 3번을 추측으로 채우지
않는다.
