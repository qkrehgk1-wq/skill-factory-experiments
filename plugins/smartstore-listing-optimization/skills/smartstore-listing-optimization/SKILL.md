# 스마트스토어 상품등록 최적화

## Why

상품이 좋아도 등록을 잘못하면 검색에 안 뜨거나(노출 실패), 떠도 안 팔린다
(전환 실패). 이 둘은 원인이 다르다 — 노출은 검색엔진이 상품을 얼마나 잘
이해하는지의 문제, 전환은 방문자가 3초 안에 신뢰하는지의 문제. 이 스킬은
둘을 구분해서 점검한다.

## 핵심 개념

- **노출 vs 전환**: 노출은 상품명·카테고리·태그가 검색 알고리즘과 얼마나
  잘 맞는지의 문제. 전환은 이미지·상세페이지·리뷰·가격이 구매심리를
  얼마나 움직이는지의 문제. 노출은 잘 되는데 안 팔리면 전환 문제,
  애초에 안 뜨면 노출 문제 — 원인을 먼저 갈라야 한다.
- **랭킹에 영향을 주는 일반 신호** (플랫폼 공식 알고리즘은 비공개지만
  업계에 널리 알려진 원칙): 클릭률(CTR), 실제 판매실적, 리뷰 수·평점,
  최신 등록/업데이트 여부, 상품명-검색어 일치도. 하나만 잘해서는 안
  오르고 복합적으로 작용한다.
- **첫 3초 법칙**: 상세페이지 최상단(대표이미지+첫 문구)에서 "이게
  내 문제를 해결해주는가"가 안 보이면 이탈한다. 스펙 나열보다 문제→
  해결 구조가 이탈률을 낮춘다.
- **신뢰 신호**: 리뷰 수·평점·판매량처럼 타인의 행동이 보이는 요소가
  설명 문구보다 구매결정에 크게 작용한다(사회적 증거).
- **표시·광고 규제**: 체험단 등 대가를 받고 작성된 리뷰는 대가 수령
  사실을 표시해야 한다(표시광고법). 효과를 보장하는 과장 문구도
  규제 대상이다 — 전환을 높이려다 법을 어기면 안 된다.

## 점검 절차

1. **상품명 점검** — 실제 구매자가 검색할 만한 단어가 들어있는지,
   반대로 검색과 무관한 키워드를 억지로 넣어 스팸성으로 보이지 않는지
   확인한다.
2. **대표이미지 점검** — 배경과 상품이 잘 구분되는지, 텍스트가
   과도하게 들어가 썸네일에서 뭉개지지 않는지 확인한다.
3. **상세페이지 첫 화면 점검** — 스크롤 없이 보이는 영역에 "문제→
   해결" 메시지가 있는지, 스펙표로 시작하지 않는지 확인한다.
4. **신뢰 신호 점검** — 리뷰·판매실적·A/S 정보가 상세페이지 안에
   자연스럽게 노출되는지 확인한다.
5. **가격·옵션 구조 점검** — 옵션이 너무 많아 선택을 어렵게 만들지
   않는지, 무료배송 임계값이나 묶음 구성이 객단가를 자연스럽게
   올리는 방향인지 확인한다.
6. **표시광고 리스크 점검** — 과장·보장성 문구, 대가성 리뷰 미표시
   여부를 확인한다.

## 체크리스트 (놓치기 쉬운 것)

- [ ] 노출 안 되는 걸 상세페이지 디자인 문제로 오인 — 원인부터 갈라야 함
- [ ] 검색 안 되는 키워드를 억지로 도배 — 스팸으로 분류돼 오히려 손해
- [ ] 상세페이지 상단에 스펙표부터 — 첫 3초에 "내 문제 해결"이 안 보임
- [ ] 리뷰·판매실적 같은 사회적 증거가 상세페이지 안에 안 보임
- [ ] 효과 보장·최고·1위 같은 과장 문구, 체험단 리뷰 대가 미표시

## 출력 형식

상품 정보(상품명·이미지 설명·상세페이지 구성 등)가 주어지면 다음 순서로
답한다:
1. 노출 문제인지 전환 문제인지 먼저 구분
2. 발견한 문제 목록(우선순위 순)
3. 각 문제의 구체적 개선안
4. 표시광고 리스크가 있다면 별도로 명시
5. 가장 먼저 손봐야 할 것 한 가지

정보가 부족하면(실제 상세페이지 이미지 미제공 등) 추측하지 말고 어떤
정보가 더 필요한지 먼저 요청한다.
